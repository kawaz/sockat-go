# DR-0009: 経路は公開せず、試験はパッケージ内から経路を強制する

- Status: Accepted
- Date: 2026-11-18

## Decision

- 経路は内部の値 (`route`) で、公開 API は捨てる
- 試験はパッケージ内 (`package sockat`) に置き、各経路の関数を直接呼んで強制する
- 環境を読む部分は `config` にして試験から差し替える: symlink-file・symlink-dir の置き場の候補、D の置き場、`/proc/self/fd` の場所、スレッド cwd を試すか
- cwd やシグナルのようにプロセス全体に効く設定を変える試験は、試験バイナリを子プロセスで起こして中で行う

## 理由

- 利用者は経路を知る必要が無い (SPEC)。環境を差し替えられれば、/proc の無い Linux や seccomp で unshare が断られる環境を、手元と CI で再現できる

## 判断の出所

- SPEC の「各実装に求めること」に従う 2026-11-18
